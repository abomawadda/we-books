# دليل تشغيل منظومة مبادرة الكتب الخارجية (الإصدار 2.3)

## التشغيل

- المنظومة تعمل على Supabase (الخادم وقاعدة البيانات) وVercel (الواجهة)، ولا تحتاج أي تركيب يدوي.
- الرابط: https://we-books-rose.vercel.app
- المهام الليلية تلقائية: مزامنة الموظفين من MyNekaba (12:30 ص) ثم إغلاق المراحل المنتهية وتحديث المتأخرات (1:00 ص).

## حسابات الإدارة الأولية (يُطلب تغيير كلمة المرور عند أول دخول)

| المستخدم | الدور | كلمة المرور المؤقتة |
|---|---|---|
| admin | المدير (كل الصلاحيات + إلغاء الإيصالات + التجاوزات) | Admin@2026 |
| coord | مسؤول المبادرة: الكتب، المراحل، الحصر، التوزيع | Coord@2026 |
| finance | أمين الصندوق: التحصيل، الأقساط، المكتبة، المصروفات | Finance@2026 |
| store | أمين المخزن: الفاتورة والجرد، التسليم، المرتجعات | Store@2026 |

## قبل الإطلاق الفعلي

- امسح البيانات التجريبية من: 03_Employees و 04_Suppliers و 05_Books_Catalog (اترك صف العناوين).
- استورد الموظفين من شاشة «الموظفون» (لصق من Excel)، ثم المكتبة، ثم الكتالوج.
- عدّل المرحلة PH-01 بمواعيدها الحقيقية، وراجع الإعدادات من «الكتب والمراحل».
- جرّب دورة كاملة بموظفَين وهميين ثم احذفهما.

## دورة كل مرحلة

1. فتح المرحلة بمواعيد الحجز ← الموظفون يحجزون.
2. بانتهاء الموعد يُغلق الحجز تلقائياً ← «تجميد الحصر» يُخرج طلب التوريد مخصوماً منه المخزون والنواقص المستحقة.
3. وصول الشحنة ← أمين المخزن يُدخل الفاتورة: السليم، التالف، ولم يُطبع.
4. «تشغيل التوزيع» ← يخصص بالأسبقية ويصدر فواتير الموظفين وجداول الأقساط.
5. الموظف يسدد المقدم عند أمين الصندوق ← يستلم من أمين المخزن بإذن تسليم مطبوع.
6. إقفال الخزينة يومياً.
7. النواقص: عند وصولها أدخل فاتورة جديدة وشغّل التوزيع، أو رحّل المنتظرين للمرحلة التالية بأسبقيتهم.
8. نهاية الموسم: تقرير «التصفية» يعرض قائمة الإغلاق؛ أرجع المتبقي للمكتبة وسوِّ رصيدها.
